# Drip Fit — «Форма роста»

Геймифицированный трекер тренировок и привычек для молодёжи: фиты за тренировки, достижения, рейтинг, друзья.

- **Модуль А** — интерфейс (папка `site/`): HTML + CSS + JavaScript, адаптивно под ПК и смартфон.
- **Модуль Б** — сервер (папка `server/`): Python + Flask, REST API, база данных SQLite.

## Быстрый запуск (Windows)

1. Нужен Python 3.10+ (при установке отметить «Add Python to PATH»).
2. Дважды щёлкнуть `start.bat`. Он сам установит Flask, создаст базу и откроет сайт **http://localhost:8000**.
3. Остановить сервер — закрыть чёрное окно или нажать `Ctrl+C`.

Вручную (любая система):

```bash
python -m pip install -r requirements.txt
python server/app.py
```

### Тестовые аккаунты

| Логин | Пароль | Что это |
|---|---|---|
| `pyaterka` (или «Пятерка») | задаётся в `config.json` → `vip_password` | аккаунт с бесконечными фитами |
| `artem_pro`, `liza_fit`, `max_power`, `sonya.run`, `dimon_iron`, `katya_yoga`, `vlad_squat`, `nastya.stretch`, `egor_cardio`, `polina_abs` | `demo123` | демо-пользователи с тренировками за 4 недели — для рейтинга и друзей |

Если `vip_password` пустой, сервер при первом запуске придумает случайный пароль и покажет его в окне. Пароль хранится только в `config.json` (он не попадает в Git) и в базе — в виде хеша.

Можно и зарегистрироваться самому — новый аккаунт заберёт то, что ты успел записать гостем.

## Что нового в этой версии

- **Учёба:** расписание из Excel по классу (с временем уроков и переменами), задачи, оценки, карточки для запоминания, фокус-таймер и время по предметам.
- **Дом:** свои дела с повтором (каждый день / раз в неделю / один раз), порядок сегодня, список покупок.
- **Деньги:** доходы и расходы по категориям, цель месяца, история по месяцам.
- **Магазин:** фоновая музыка «Lofi-радио 24/7» — самая дорогая покупка (3000 фитов); адрес стрима — `lofi_url` в `config.json`.
- **Путеводитель** — кнопка в правом нижнем углу главной: ответы на частые вопросы о сайте.
- Все покупки и данные новых вкладок сохраняются в аккаунте на сервере.

## Что делает сервер

- Регистрация и вход, пароли хранятся хешем (werkzeug), вход по токену сессии.
- CRUD пользователя, тренировок, упражнений в тренировке, результатов (повторы, вес, время, дистанция).
- Статистика за период, личные рекорды, рейтинг по выбранному показателю (фиты, тоннаж, дни, кардио, серия).
- Друзья: заявки, принятие, удаление. Достижения: прогресс и получение награды.
- Фиты за тренировку — один раз в день, серия дней подряд считается на сервере.
- Синхронизация: всё, что сайт хранит в браузере (планы, питание, вода, настройки графиков…), сохраняется в аккаунте.
- Магазин: `GET /api/shop/music` (адрес фоновой музыки), `POST /api/shop/buy` (покупка за фиты на сервере).
- Внешние API: поиск видео на YouTube (YouTube Data API v3) и поиск музыки (iTunes Search API, 30-секундные отрывки + ссылка на Яндекс Музыку).

Без сервера сайт тоже работает (данные в браузере) — так он опубликован как макет модуля А.

## Ключ YouTube (по желанию)

Без ключа поиск показывает видео из библиотеки сайта и ссылку на поиск YouTube. Чтобы искать прямо на YouTube:

1. Зайти в https://console.cloud.google.com/ → создать проект.
2. «APIs & Services» → «Library» → найти **YouTube Data API v3** → «Enable».
3. «Credentials» → «Create credentials» → «API key» → скопировать ключ.
4. Открыть `config.json` (создаётся при первом запуске из `config.example.json`) и вставить ключ в `"youtube_api_key"`.
5. Перезапустить сервер.

Ключ хранится только на сервере и в Git не попадает (`config.json` в `.gitignore`).

## Доступ с телефона в той же Wi-Fi

В `config.json` поставить `"host": "0.0.0.0"`, перезапустить сервер и открыть на телефоне `http://<IP компьютера>:8000`
(IP — команда `ipconfig`, строка «IPv4-адрес»). Windows может спросить разрешение для Python в брандмауэре — разрешить для частной сети.
